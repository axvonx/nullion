# Debug glitch text samples

Lines for the debug rail’s glitch-text cycler (`←` / `→` arrow keys).
Syntax: `{gl:base|glitch}` swaps or inserts `glitch` briefly over `base`.

- You weren’t {gl:|(YES YOU WERE!) }supposed to find that.
- A {gl:classic|suspiciously common} pick.
- Nobody else {gl:thought of|admitted to} that one.
- Deep cut. {gl:Very few|Almost zero} found it.
- That one {gl:hides from|actively avoids} almost everyone.
- {gl:One in a billion.|Actually, 1 in 4,294,967,296.} Well, almost.
- The stack {gl:accepted|tolerated} your answer.
