# Hidden Beacon

id: rf-tower · tag: AMT-BEACON(−3) · kind: prop · rarity: mythic · status: approved · page: 34

Broadcasts silent 1-bit pings from the bottom of the silicon die, even when the machine is asleep.

> Out-of-band management engines can answer network pings while the main CPU is powered down.
