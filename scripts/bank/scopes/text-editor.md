# Scope: Name a text editor
id: text-editor · by: claude (draft: owner may veto), 2026-11-27

A program whose main purpose is editing plain text files: terminal or GUI, current or historical, on any operating
system. Source-code editors count; full IDEs, word processors and note apps do not.

## Sub-kinds
- vi family and modal editors: vi, Vim, Neovim, nvi, elvis, vile, Helix, Kakoune, vis
- Emacs family: GNU Emacs, XEmacs, mg, Zile, JOVE, MicroEMACS, Epsilon
- modeless terminal editors: nano, pico, micro, JOE, jed, ne, dte, mle
- line and historical editors: ed, ex, QED, TECO, Edlin, SOS, XEDIT, sam's command language
- desktop GUI editors: Notepad, TextEdit, gedit, Kate, Mousepad, Leafpad, Pluma, Xed, GNOME Text Editor
- programmer's and code editors: VS Code, Sublime Text, Notepad++, Atom, Zed, BBEdit, TextMate, UltraEdit, Geany, jEdit
- Plan 9 and research editors: sam, acme, Wily

## In
- Any operating system, current or historical: Windows, macOS, DOS, Plan 9, mainframes, Unix.
- Source-code editors whose main job is editing text files (VS Code, Sublime Text, Zed), even with plugins.
- Clones, forks and rewrites with their own name (Neovim, nvi, elvis, Lite XL), and modes that are their own
  program name (ex).

## Out
- IDEs whose main job is building and debugging projects: IntelliJ IDEA, Eclipse, Visual Studio, Xcode, Android Studio.
- Word processors and rich-text editors: Microsoft Word, WordStar, LibreOffice Writer, WordPad.
- Note-taking and knowledge apps: Obsidian, Notion, Evernote, OneNote, Joplin.
- Hex, binary, image and structured-data editors (HxD, a spreadsheet, a HTML WYSIWYG designer like Dreamweaver).
- Editor components and libraries (Scintilla, CodeMirror, Monaco, Ace), plugins, configuration distributions
  (Spacemacs, Doom Emacs, LazyVim) and online services (Google Docs).

## Examples
- off-by-one: Vim, Emacs, VS Code, Notepad, Sublime Text, Notepad++
- npe: nano, gedit, Kate, vi, Atom, ed, TextMate
- leak: JOE, jed, TECO, Mousepad, jEdit, nvi
- race: sam, mg, Zile, vile, Textadept, JOVE
- heisenbug: dte, mle, Yudit, xcoral, Acme, THE
