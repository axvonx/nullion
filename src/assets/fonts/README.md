# Fonts

`texgyretermes-{regular,bold,italic}.woff` are TeX Gyre Termes (GUST e-foundry), a free Times Roman revival based on
URW Nimbus Roman No9 L. They are the unmodified fonts from CTAN (`fonts/tex-gyre/opentype`), only rewrapped as
WOFF. License: the GUST Font License (`GUST-FONT-LICENSE.txt`), an instance of the LaTeX Project Public License.
Used by the Field Manual binder (`src/ui/binder/`), loaded only when it opens.
